# Просмотр крафтов предмета (View Crafts)

## Описание

Фича позволяет быстро узнать, как предмет используется в системе крафта, не открывая XML-файлы. Через меню действия предмета («шестерёнка» — клик по картинке предмета в окне описания) доступен пункт **«Просмотр крафтов (Текст)»**, который выводит все рецепты, связанные с выбранным предметом, прямо в игровой лог сообщений.

## Использование

1. Откройте окно описания предмета (в инвентаре наёмника или в сектором инвентаре).
2. Кликните левой кнопкой мыши по картинке предмета — откроется меню трансформаций (Transformation Menu).
3. Выберите пункт **«Просмотр крафтов (Текст)»** — он есть в меню всегда, для любого предмета.
4. Рецепты будут выведены в тактический лог (и лог экрана карты).

## Что выводится

Сначала — заголовок **белым цветом** с названием предмета и его индексом:

```
===== Труба (308): КРАФТ =====
```

Затем — найденные рецепты **оранжевым цветом**. Выводятся три типа рецептов:

### 1. Предмет является ингредиентом (Merge)

Предмет используется вместе с чем-то для получения результата:

```
Используется для: Труба + Глушитель = Хвостовик
```

### 2. Предмет можно скрафтить (результат рецепта)

Показывает, из чего состоит рецепт, где предмет — результат:

```
Можно скрафтить из: Аптечка + Медкомпоненты => Аптечка полевая
```

Особый случай — рецепты из `AttachmentComboMerges.xml` (базовый предмет + вложения), они выводятся с тремя ингредиентами:

```
Можно скрафтить из: Труба + Глушитель + Дрель => Хвостовик
```

### 3. Самопревращение предмета (Item_Transformations)

Если предмет превращается в другой без добавления ингредиентов:

```
Создается из: Металлический лом => Гвоздодёр
```

Если рецептов нет, выводится жёлтое сообщение:

```
Рецептов крафта для этого предмета не найдено.
```

## Какие системы крафта охватываются

Фича собирает рецепты из всех трёх механизмов крафта 1.13:

| Механизм | XML-файл | Пример |
|---|---|---|
| Merge (предмет + предмет) | `TableData\Items\Merges.xml` | Аптечка + медкомпоненты |
| AttachmentComboMerge (база + вложения) | `TableData\Items\AttachmentComboMerges.xml` | Труба + Глушитель + Дрель = Хвостовик |
| Transformation (самопревращение) | `TableData\Items\Item_Transformations.xml` | Лом → Гвоздодёр |

Поиск выполняется в обе стороны: и «что можно сделать из предмета», и «из чего можно сделать предмет».

## Технические детали (для разработчиков)

- **Файлы**: `Tactical\CraftInfo.h`, `Tactical\CraftInfo.cpp`
- **Класс**: `CraftInfo` — в конструкторе принимает `usItemIndex` и собирает рецепты в `std::vector<CraftRecipe>`; методы `CollectMergeRecipes()`, `CollectComboMergeRecipes()`, `CollectTransformationRecipes()`; `Print()` отвечает за вывод
- **Точка входа**: `void ShowItemCraftInfo(UINT16 usItemIndex)` — собрать и вывести одной строкой кода; может использоваться любым будущим GUI
- **Точка вызова**: `TransformationMenuPopup_CraftInfo()` в `Tactical\Interface Items.cpp` (callback пункта меню Transformation Menu)
- **Вывод**: `ScreenMsg(FONT_ORANGE/FONT_MCOLOR_WHITE/FONT_MCOLOR_LTYELLOW, MSG_INTERFACE, ...)` — виден и в тактическом логе, и в логе экрана карты
- **Локализация**: строки вынесены в `gzCraftInfoMessage[]` — `Utils\Text.h` (enum `CRAFTINFO_*`), `_EnglishText.cpp`, `_RussianText.cpp`
- Рецепты фильтруются по `ItemIsLegal()` — недоступные в текущей кампании предметы не показываются

## Ограничения (MVP)

- Вывод текстовый, без GUI — рецепты занимают строки лога (у лога ограниченная история)
- Не показываются: стоимость AP, тип мерджа (лёгкий/тяжёлый/электронный), требования к навыку — только состав рецепта
- У ComboMerge-рецептов с большим числом вложений показываются первые два, остальные отбрасываются
