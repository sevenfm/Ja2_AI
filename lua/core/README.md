# Lua 5.1.5 — ядро (core)

## Происхождение

Исходники официального релиза **Lua 5.1.5** (Copyright (C) 1994-2012 Lua.org, PUC-Rio,
лицензия MIT — см. заголовки файлов), скопированы из репозитория JA2 1.13
(`D:\Projects\Ja2_1dot13_source\source\ext\lua-5.1.5\src`), который берёт их из
официального дистрибутива `lua-5.1.5.tar.gz` без изменений.

**Файлы `lua.c`, `luac.c`, `print.c` не включены** — это standalone-интерпретатор и
компилятор, они не нужны для встраивания в JA2.

## История в этом проекте

- До 11.2026 ядро Lua 5.1.2 не собиралось из исходников — использовался
  прекомпилированный `lua51.lib` (лежал в корне репозитория, линковался через
  `ja2_Libs.props`).
- 11.2026 (ветка `feature/lua-port-515`): прекомпилированный lib удалён, ядро Lua
  обновлено до 5.1.5 и добавлено в компиляцию проектов `lua_VS2013.vcxproj` и
  `lua_VS2010.vcxproj`. Публичные заголовки (`lua\lua.h`, `lauxlib.h`, `luaconf.h`,
  `lualib.h`) синхронизированы с 5.1.5.

## Соглашения сборки

- C-файлы компилируются как C (не C++), runtime-библиотека та же, что у проекта `lua`.
- Файлы включают `"lua.h"` и т.п. локально из этого каталога — конфликтов с
  `lua\lua.h` нет: оба экземпляра идентичны (5.1.5).
- Единственное функциональное отличие 5.1.2 -> 5.1.5, влияющее на код:
  `LUAI_MAXCSTACK 2048 -> 8000`. Обратная совместимость полная (Lua 5.1 ABI).

## Обновление ядра Lua

При обновлении (например, до будущей Lua 5.1.6, если появится):
1. Заменить все `*.c`/`*.h` в этом каталоге на файлы из `src/` нового релиза
   (опять же без `lua.c`, `luac.c`, `print.c`).
2. Синхронизировать публичные заголовки в `lua\` (`lua.h`, `lauxlib.h`, `luaconf.h`, `lualib.h`).
3. Проверить сборку и прогнать smoke-тест Lua-контента (шахты, квесты).
4. Номер версии отражён в `lua\lua.h` (`LUA_RELEASE`).
